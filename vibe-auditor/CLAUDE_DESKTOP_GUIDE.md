## Location for Claude Desktop Skills:

Windows:
C:\Users\YOUR_NAME\.claude\skills\vibe-auditor\

Mac:
~/.claude/skills/vibe-auditor/

OR Global Claude Desktop Config:
Windows: %APPDATA%\Claude\claude_desktop_config.json
Mac: ~/Library/Application Support/Claude/claude_desktop_config.json

For Claude Desktop, just copy .claude/skills/vibe-auditor folder to above path and restart Claude Desktop.
Then type: /vibe-auditor
